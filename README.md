# [Bike Sales Analysis Dashboard]

## 🎯 Project Overview
This project focuses on analyzing Bike sales of an international Bike seller company to identify key trends, performance bottlenecks, and growth opportunities. 
The project were part of the Udemy course named Data Analysis | SQL, Tableau, Power BI, Excel | Real Projects. 
This dashboard was created using a dataset downloaded from the course, but also available in Kaggle.

* **Live Dashboard:** https://public.tableau.com/app/profile/fabi.n.vargas.ruiz/viz/bikesales_17827981201220/SalesDashboard?publish=yes

---

## 🛠️ Tech Stack & Tools
* **Data Visualization:** Tableau Public
* **Data Processing:** Excel, however in this particular project, data was used as it were on the xlsx
* **Dataset Source:** Kaggle / Udemy Course. I downloaded from the course files available.

---

## 🚀 Key Insights & Business Value
* **Insight 1:** At the first years, Road bikes were very present in the Top 10 products sold, second is Mountain Bikes. However through the years 
and getting new products lines available, some of these products has removed bikes as the most sell products.
* **Insight 2:** Confirmed that Adults and Young Adults are the segments buying the most, which was something expected.
* **Insight 3:** United States and Australia are the countries in which we are doing best. 
* **Insight 4:** Both men and women are buying our products, so our campaings are well designed to reach both.

## 🔧 Data Preparation Process
In this case, the dataset provided were not cleaned or transformed in any way.
Formulated custom metrics using Tableau LOD (Level of Detail) expressions and window calculations to track rolling averages.
